# Mohammad Ayaan Khan - Personal Portfolio

A responsive resume and portfolio for a BBA in Digital Business and Entrepreneurship student at IIM Bangalore.

## Links

- Live website: https://m-ayaan-khan-01.github.io/portfolio/
- Repository: https://github.com/M-Ayaan-Khan-01/portfolio

## Structure

- `index.html`: semantic content, inline SVG monogram and mobile menu interaction.
- `styles.css`: colours, typography, Flexbox navigation, Grid layouts, responsive breakpoints, focus states, reduced-motion and print rules.
- `assets/`: existing downloadable resume and supporting resources from the previous version.

## Sections and design

The page introduces Ayaan, explains editorial and Model United Nations experience, presents academic achievements, groups business and communication skills, identifies ongoing learning, shares professional interests, and provides email and LinkedIn contact links.

A cream background, forest-green accents and system serif/sans-serif fonts create an editorial design without external font downloads. The navigation collapses to a keyboard-accessible menu on small screens. Ongoing qualifications are explicitly labelled as in progress.

## Run and publish

Open `index.html` locally, or run `python3 -m http.server 8000` in this folder and visit http://localhost:8000.

GitHub Pages publishes the `main` branch from `/ (root)`. Update `index.html` and `styles.css` together; no build step or package installation is needed.
