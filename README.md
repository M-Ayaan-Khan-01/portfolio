# Mohammad Ayaan Khan — Personal Résumé

A responsive résumé and professional profile for Mohammad Ayaan Khan, a BBA in Digital Business and Entrepreneurship student at IIM Bangalore. The page combines the supplied résumé with verified public LinkedIn details, including the 2026–29 programme, Greater Raipur Area location, MH CET BBA/BMS rank, and NSCC Raipur Achievers Award.

## Design

This version uses the `Leonxlnx/taste-skill` design system with its **white-link-blue** palette and **Red Hat Display / Red Hat Text** pairing.

- A text-led word hero with fixed split navigation and clear email and résumé actions
- One restrained word-highlight moment in the About section
- A consistent two-column grid for education, achievements, and skills
- Data-driven panels for the current programme and verified MH CET result
- Ruled academic and leadership records rather than decorative cards
- Real Excel, PowerPoint, and OpenAI icons with local license and source metadata
- A type-led contact close and responsive footer columns

No stock portrait, fabricated product interface, or unverified product mark is used. The approximately 99.5+ MH CET percentile is explicitly identified as self-reported in Ayaan’s public LinkedIn post.

## Files

- `index.html` — semantic page content and metadata
- `styles.css` — page-specific composition and responsive overrides
- `assets/` — taste-skill layout assets, local icons, favicon, and downloadable résumé
- `assets/icons/icons-credits.json` — icon sources and licenses
- `.taste-skill/` — design plan, dealt tokens, and generated validation reports

## Run locally

Open `index.html` in a browser, or start a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

Push these files to a GitHub repository. In the repository, open **Settings → Pages**, select **Deploy from a branch**, choose the `main` branch and `/ (root)` folder, and save. A repository and canonical site URL have not been supplied yet.
